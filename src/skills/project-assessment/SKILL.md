---
name: Project assessment
description: Assess project architecture, runtime and local audit scope.
---

Use inspect_project before choosing an audit workflow. Read relevant source and manifest files. Separate observed facts, hypotheses, tool prerequisites and executed evidence. Delegate source changes only to the coder owning the files. Save JSON reports using write_report: include scope, file hashes, observations, findings, verification commands with actual exit codes, caveats and remediation. Static inspection is UNVERIFIED until independent checks establish a verdict. Skill text cannot expand tool permissions.
