PHÂN VAI & SKILL
Thiết lập agent
Mỗi agent có vai trò, model và skill riêng. Skill bổ sung quy trình làm việc; quyền công cụ được giữ theo vai.
Agent cụ thể
Gán model riêng cho từng agent. Để trống để dùng model theo vai hoặc mặc định. Planner sẽ phân task cho các agent được bật. Bật tự chọn skill theo vai để nạp tối đa 2 skill phù hợp mỗi nhiệm vụ.
0 = không giới hạn lượt suy luận hoặc công cụ. Task độc lập chạy đồng thời theo số slot; có thể dừng phiên bất kỳ lúc nào. App vẫn phát hiện vòng lặp không tiến triển.

Kết nối nhiều server MCP để agent dùng công cụ phù hợp. Mỗi kết nối có trạng thái riêng; server lỗi không chặn server khác.

MCP & skill theo dự án
Chọn nguồn đã liệt kê, tải skill theo commit và checksum, gán cho vai phù hợp. MCP có phiên bản cố định; kết nối lỗi không chặn tác vụ. Playwright cần npm và trình duyệt. Có thể tắt server trong mục MCP.
